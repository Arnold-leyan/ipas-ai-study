AI 的三層架構 p.3-3～3-4

① 技術底層

提供計算能力、數據支撐與核心演算法。五個要素：

  • 資料處理與分析：數據清理、整合、儲存、分析。關鍵技術如 ETL（Extract, Transform, Load）、資料庫管理、大數據處理平台（Hadoop、Spark）
  • 演算法：解決問題與決策支援的邏輯基石。迴歸分析、分類演算法、決策樹、基因演算法
  • 機器學習：透過資料訓練模型來預測或分類。監督式、非監督式、強化學習
  • 深度學習：建於人工神經網路之上，適用非結構化數據（語音、影像、NLP）。框架如 TensorFlow、PyTorch
  • 專家系統：基於規則與知識庫模擬人類專家的決策過程，用於醫療診斷、財務分析

② 開發應用

把基礎技術轉化為實際功能與服務：模型設計 → 訓練 → 測試 → 部署。目標是解決特定業務需求。

③ 實際運用

  • 設計行業解決方案：智慧醫療、智慧物流、智慧製造
  • 打造產品與服務：語音助理、推薦演算法、智慧監控系統
  • 優化業務流程：提高運營效率與競爭力

資料處理四步驟 p.3-4～3-7

蒐集 → 清洗 → 轉換 → 分析。今天讀前三步，第四步（分析）明天讀。

① 數據蒐集：三種數據結構

類型特徵儲存形式與例子
結構化清晰且固定結構，行列形式，便於直接查詢分析關聯式資料庫 MySQL、PostgreSQL、規範化電子表格
半結構化有結構標籤但格式靈活，無需嚴格遵循固定架構，適合層次化數據文件形式：XML、JSON、CSV
非結構化無固定結構，需經處理解析後才能分析檔案形式：圖片、影像、音訊、電子郵件、文章

常見蒐集方法

  • 問卷與調查：線上或線下直接蒐集第一手數據，用於市場研究、用戶回饋
  • 自有產品數據：自有網站、App，或實體裝置如智慧手錶、汽車
  • 外部公開數據：API 調用（政府開放平臺）或網路爬蟲擷取公開數據
  • 外部付費數據購買：與第三方數據提供商合作，如市場調查、人口統計數據

② 數據清洗：四種值

問題怎麼處理
遺缺值
Missing		填補（平均值／中位數／眾數、插補法 Interpolation、迴歸等預測模型）或刪除記錄（占比高或不可修復時，需評估對樣本代表性的影響）
重複值
Duplicate		透過主鍵、唯一識別碼或關鍵欄位識別，保留一份正確記錄、刪除其他
錯誤值
Error		檢測並修正不符合合理範圍的值。例：年齡 −5 歲、Taiwan 拼成 Taiwwn
離群值
Outlier		明顯偏離其他數據點的異常值。通常可能是有意義的數據而非錯誤值，需依業務需求與分析目標採取適當策略
最容易被出成陷阱的一句 離群值 ≠ 錯誤值。錯誤值一定要修（年齡不可能是負數）；離群值可能反映真實的異常情況，也可能是雜訊， 不能一律刪除。看到選項寫「離群值應直接刪除」就要警覺。

③ 數據轉換：五種

轉換做什麼例子
格式轉換一種檔案格式轉成另一種CSV → JSON
類型轉換一種資料型別轉成另一種字串 → 數值
正規化／標準化縮放到特定範圍，消除單位影響、使變數可比較[0,1] 或 −1～1
離散化連續型數據切成區間或類別年齡 → 青年／中年／老年
縮減特徵選擇、特徵提取或降維，減少維度與體積主成分分析 PCA
