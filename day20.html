快速複習①：鑑別式AI vs 生成式AI 科目一 p.3-48～3-49

鑑別式AI（Discriminative AI, DAI）與生成式AI（Generative AI, GAI）是人工智慧的兩大分支，分別代表數據分析與數據創造：

鑑別式AI生成式AI
學習目標條件概率 P(y│x)，找分類邊界聯合分佈 P(x,y) 或邊際分佈 P(x)
任務分類、迴歸、預測生成具創新性的新樣本
代表模型邏輯迴歸、SVM、決策樹、隨機森林、神經網路GAN、VAE（變分自編碼器）、擴散模型（Diffusion Models）
輸出分類標籤或數值預測新的數據樣本（文字、圖像、音訊）
應用實例醫學影像分類、信用風險評估、垃圾郵件偵測ChatGPT 生成對話、DALL-E 創作圖像、Deepfake 影音合成

整合應用：兩者常協同運作——生成式AI 生成多樣化數據（解決數據稀缺、不平衡問題），鑑別式AI 再對這些數據分類分析。例如醫療影像領域，GAN 生成病變模擬影像，讓鑑別式AI 模型訓練得更準確；自動駕駛領域，生成式AI 模擬各種天氣路況，讓鑑別式AI 學會應對複雜情境。

白話一點：鑑別式 AI 像「鑑定師」，生成式 AI 像「創作者」

鑑別式AI：像古董鑑定師，拿到一件東西就判斷「這是真的還假的」「這屬於哪個朝代」——它不會自己做出一件古董，只負責判斷、分類。生成式AI：像藝術家，看過大量作品後，自己動手畫出一幅新的畫——重點在創造出原本不存在的東西。GAN 就是這兩種角色的結合：生成器（創作者）不斷畫、鑑別器（鑑定師）不斷抓破綻，兩邊一起進步。

快速複習②：No Code／Low Code 重點回顧 科目二 p.3-1～3-16

W2 學過的內容，這裡只列最容易忘記、也最容易考的幾點：

  • No Code vs Low Code：差在要不要寫程式碼、寫多少，不是有沒有介面（兩者都有）。No Code＝完全不用寫；Low Code＝可以寫一點做客製化。
  • AI 民主化：把 AI 從少數專家、大型企業，擴展到更廣泛的社會層面（非技術背景人士、中小企業）。No Code/Low Code 平台是實現它的工具，AI 民主化才是目標。
  • 市民開發者（Citizen Developer）：非技術背景人士利用 No Code/Low Code 工具自動化日常工作。
  • TCO vs ROI：TCO 算投入（購買維護培訓成本）；ROI 算產出（效益回報）——跟今天學的 ROI 計算方式是同一個概念的延伸。
