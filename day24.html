統一筆記 A：鑑別式AI vs 生成式AI

核心對照 科目一 p.3-48～3-49

鑑別式AI（DAI）生成式AI（GAI）
學習目標條件概率 P(y│x)，找分類邊界聯合分佈 P(x,y) 或邊際分佈 P(x)
任務分類、迴歸、預測生成具創新性的新樣本
代表模型邏輯迴歸、SVM、決策樹、隨機森林、神經網路GAN、VAE（變分自編碼器）、擴散模型（Diffusion）
輸出分類標籤或數值預測新的數據樣本（文字、圖像、音訊）
  • GAN＝生成器＋鑑別器對抗；VAE＝編碼器＋解碼器（映射到隱變量空間再重建）；擴散模型＝逐步去雜訊，適合高維圖像生成。
  • 整合應用：生成式AI 生成多樣化數據（解決數據稀缺、不平衡）→ 鑑別式AI 再分類分析。例：GAN 生成病變模擬影像，讓鑑別式模型訓練得更準。

白話

鑑別式AI 像鑑定師（判斷這是真是假、屬於哪類）；生成式AI 像創作者（畫出一幅新的畫）。GAN 就是這兩個角色的結合：生成器一直畫、鑑別器一直抓破綻。

統一筆記 B：No Code / Low Code 概念

核心對照 科目二 p.3-1～3-2

No CodeLow Code
要不要寫程式完全不用寫，純拖放可以寫一點，做客製化與複雜邏輯
視覺化介面有有（分界不是有沒有介面）
使用族群非技術背景使用者具基本技術背景、需高彈性／深度整合（串 CRM、ERP）
適合場景快速原型、小型應用（活動報名表單）中大型企業級、複雜邏輯

關鍵名詞 科目二 p.3-8～3-16

名詞重點
AI 民主化目標：把 AI 從少數專家、大型企業擴展到更廣泛的社會層面（非技術者、中小企業）。No Code/Low Code 是實現它的工具。
市民開發者（Citizen Developer）人：非技術背景人士用 No Code/Low Code 工具自動化日常工作（報告生成、數據輸入）。
選平台的考量功能與擴展性看技術整合能力與自訂性；另有成本效益（TCO vs ROI）、安全合規（GDPR、CCPA）、技術支援。
TCO vs ROITCO 算投入（購買＋維護＋培訓）；ROI 算產出（效益回報）。
結合生成式AI 的挑戰模型準確性、資料隱私安全、道德倫理風險、技術整合適配；克服四面向：數據品質管理、模型效能評估、人機協作機制（關鍵應用設人工審核）、安全防護。
不適合的應用自動生成法律判決（需專業法律知識與嚴格合規審查）。

技術架構與推理機制 科目二 p.3-17～3-18

面向重點
深度學習網路多層神經網路、注意力機制（自注意力處理長距離依賴）
訓練數據處理清洗、標記化（Tokenization）、向量化（Vectorization）
推理機制溫度參數控制隨機性（高＝創意）；Top-k 取機率前 k 個；核採樣（Nucleus）取累積機率達 0.9 的選項

挑戰關鍵字：計算資源、硬體限制、輸出準確性、AI 幻覺（hallucinations）、偏見與安全性。

市場、就業與工具演進 科目二 p.3-18～3-22

  • 就業變革：重複性、低技能工作被取代；新增 AI 訓練師、提示工程師（Prompt Engineer）。
  • 經濟效益三層：直接（降成本提效率）、間接（促進創新、新商業模式）、衍生（帶動 AI 硬體與雲端服務）。
  • 技術突破：GAN、VAE／流式模型、Transformer 與自注意力、預訓練＋微調＋RLHF（人類回饋強化學習）、高效推理（vLLM）。
  • 開源社群：Hugging Face 提供開源資源，加速整合。

9 大發展趨勢（常考 ③）＋ 五大產業應用 科目二 p.3-22～3-26

趨勢：①專業化垂直整合 ②多模態整合 ③AI 即服務（AIaaS）——雲端 API（OpenAI API、Hugging Face Spaces） ④個人化可控性 ⑤協作即時回饋 ⑥安全隱私（本地部署、加密、內容過濾） ⑦效能優化 ⑧生態系建構 ⑨道德法律規範（版權、防深偽假新聞）。

五大產業應用：藝術設計／內容創作、醫療與生物科技、教育與培訓、娛樂與媒體、產品設計與製造。

一分鐘回想

鑑別式＝P(y│x) 分類、生成式＝P(x,y) 生成；GAN 生成器＋鑑別器、VAE 編碼器＋解碼器、擴散去雜訊。No Code vs Low Code 差在寫不寫程式不是有沒有介面；民主化＝目標、市民開發者＝人、平台＝工具；TCO 投入、ROI 產出。科目二 3.2：推理機制＝溫度／Top-k／核採樣，挑戰有 AI 幻覺，新職務 提示工程師，趨勢最常考 AIaaS，關鍵詞 RLHF、Hugging Face。
